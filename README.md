# Market Intelligence

Персональный монитор финансовых новостей. Источники опрашиваются по индивидуальному расписанию. Публикации, версии текстов, пользовательские настройки, видеоотчёты и очередь доставки хранятся в SQLite. Для управления используется личный чат с Telegram-ботом.

## Первый запуск на Windows

Программу запускает один из вас на одном компьютере. Руслан и Яна пользуются одним ботом через свои личные чаты. Оба могут добавлять источники, менять общий список инструментов и настройки. Команда `/pause` ставит рассылку на паузу для обоих.

1. Установите [Git для Windows](https://git-scm.com/downloads/win) и [Python 3.12 для Windows](https://www.python.org/downloads/windows/). При установке Python включите Python Launcher.
2. Откройте PowerShell через меню «Пуск» и выполните команды по очереди.

```powershell
git clone https://github.com/TiM3la/MarketIntelligenceApp.git
cd MarketIntelligenceApp
```

3. В том же окне выполните следующие команды. Они создадут отдельное окружение проекта, установят зависимости и откроют ваш файл настроек в Блокноте. Если установлен Python 3.11, замените `-3.12` на `-3.11`.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

4. Создайте одного бота командой `/newbot` в Telegram у **@BotFather**. В открытом Блокноте вставьте выданный токен сразу после `TELEGRAM_BOT_TOKEN=`, сохраните файл (Ctrl+S) и закройте его. Для первой проверки достаточно этого токена.
5. Выполните команду ниже и оставьте окно открытым. Отправьте второму участнику ссылку на бота, которую выдал BotFather. **Каждому нужно открыть чат с ботом по этой же ссылке и нажать «Начать».** Командой `/test` каждый проверяет свой чат. После включения источника автоматические новости приходят обоим.

```powershell
.\.venv\Scripts\python.exe -m app.main
```

Остановка — Ctrl+C. Однократный опрос всех активных источников, для которых подошло время проверки, выполняет `python -m app.main once`. При первом запуске все источники выключены. Без Telegram-токена приложение продолжит опрашивать ранее настроенные источники и накапливать уведомления.

## Первая публикация

Вызовите `/sources` и найдите номер Federal Reserve. Выполните `/source ID enabled 1`, подставив номер. Адрес ленты взят из [официального каталога ФРС](https://www.federalreserve.gov/feeds/feeds.htm). Остальные записи начального каталога — редактируемые шаблоны без адреса. Чтобы подключить собственную ленту, отправьте боту:

```text
/add_source rss https://www.federalreserve.gov/feeds/press_all.xml Пресс-релизы ФРС
```

Первый опрос импортирует текущие элементы ленты. Если хотите сначала посмотреть архив без уведомлений, отправьте `/pause` до подключения. При `/resume` накопленная очередь будет доставлена. В `/sources` виден результат проверки, в `/recent` — последние события. `/event 1` показывает последнюю версию текста, время обнаружения, доступное время публикации и ссылки. Журнал ошибок хранится в `data/market.log`.

### Повседневное управление

| Команда | Действие |
|---|---|
| `/add_source site URL Название` | Добавить статическую HTML-страницу. По умолчанию читаются article или body. CSS-селектор задаётся через `/source ID selector article.news`. |
| `/source ID interval 300` | Задать опрос раз в пять минут. Минимум 15 секунд. |
| `/source ID trust 2` | Повысить вклад доверия к источнику в оценку важности. Допустимы 0–3. |
| `/source ID enabled 0`, `/remove_source ID` | Выключить или убрать источник из списка. Архив сохраняется. |
| `/categories Инфляция РФ \| индекс потребительских цен,ипц` | Создать или изменить правило категории. |
| `/watchlist TEST \| Тестовый актив \| акция \| ключевое слово \| Corporate News \| базовый актив` | Задать собственный инструмент. В Telegram вводите обычный вертикальный разделитель. |
| `/settings minimum HIGH`, `/settings filter Inflation,Central Banks` | Выбрать порог и категории новых уведомлений. Пустое значение filter возвращает все категории. |
| `/settings language en`, `/settings timezone Europe/Moscow` | Язык подписей новостных уведомлений и часовой пояс. Текст источника остаётся в оригинале. |
| `/settings digest_minimum NORMAL`, `/digest` | Получить до 20 событий за сутки с учётом категории и порога дайджеста. |
| `/search слово`, `/saved`, `/analysis ID`, `/report ID` | Поиск, избранное, анализ новости и отчёт по видео. |
| `/schedule 2027-01-15T15:00:00+03:00 \| Тест \| Пользователь \| Other` | Добавить событие календаря. Напоминание ставится в очередь в пределах 15 минут до начала. |
| `/calendar`, `/result ID текст` | Посмотреть календарь и опубликовать полученный результат. |

## Дополнительные подключения

**Telegram-каналы.** Получите api_id и api_hash своего приложения на my.telegram.org, заполните TELEGRAM_API_ID и TELEGRAM_API_HASH. Выполните один раз `python -m app.main login`. Введите телефон, код и пароль двухэтапной проверки в локальном терминале. Запустите службу и добавьте `/add_source telegram @имя_канала Название`. Читаются последние 50 сообщений при подключении, затем новые сообщения и недавние правки. Текстовые подписи к медиа сохраняются. Файл сессии предоставляет доступ к аккаунту. Храните каталог data и .env в личном профиле с ограниченными правами Windows.

**Бесплатный ИИ для теста.** Создайте ключ на [странице ключей OpenRouter](https://openrouter.ai/settings/keys). В локальном файле `.env` добавьте строку `OPENROUTER_API_KEY=ваш_ключ` и перезапустите бота. Приложение использует [openrouter/free](https://openrouter.ai/openrouter/free). Публикация и её ссылка передаются провайдеру. Новости HIGH и CRITICAL обрабатываются автоматически. Для любой новости нажмите «AI-анализ», затем откройте результат той же кнопкой. Повторное открытие сохранённого разбора расходует ноль запросов. При ошибке провайдера бот повторит попытку позже, сбор новостей продолжится.

Для другого совместимого API оставьте OPENROUTER_API_KEY пустым и задайте LLM_API_KEY, LLM_BASE_URL и LLM_MODEL.

**YouTube.** Добавьте `/add_source youtube UC… Название`, где UC… — полный 24-символьный ID канала. Видео обнаруживаются через Atom. Обработчик сначала ищет русские или английские субтитры в формате json3, затем, при включённой опции, распознаёт доступную аудиодорожку. Для распознавания установите FFmpeg в PATH, выполните `python -m pip install faster-whisper` и задайте WHISPER_ENABLED=1. При первом распознавании модели требуется загрузка. WHISPER_MODEL задаёт размер модели. VIDEO_ENABLED=0 отключает обработку, сохраняя обнаружение видео. Отчёт содержит выдержки с привязкой к началу шестиминутных фрагментов. Длинные отчёты доставляются частями.

## Docker

Установите Docker с Compose, подготовьте .env по инструкции выше и выполните:

```powershell
docker compose build
docker compose run --rm monitor python -m app.main login
docker compose up -d
docker compose logs -f
```

Команда login нужна только для чтения Telegram-каналов. При изменении WHISPER_ENABLED пересоберите образ. База, логи и сессия находятся в томе market-data, начальные конфигурации подключены из config. Остановка — `docker compose down`. Для резервной копии остановите службу и скопируйте весь каталог data или том. Запускайте один экземпляр с каждой базой и токеном.

## Тестирование и устройство

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
.\.venv\Scripts\python.exe -m app.main once
```

Тесты используют временную SQLite, локальный HTTP-сервер, фиктивные ответы Telegram, AI и видео. Платные запросы не выполняются. app/collect.py отвечает за источники, store.py и schema.sql — за хранение и классификацию, bot.py — за команды, analysis.py и video.py — за аналитику. main.py запускает независимые циклы мониторинга, доставки и анализа. Версия начальной схемы хранится в PRAGMA user_version.

## Границы MVP

Статические сайты требуют подходящей разметки или селектора. Авторизация на сайтах, исполнение JavaScript и обход ограничений не поддерживаются. Интервалы источников, доступность сторонних сервисов и задержки самих лент влияют на скорость обнаружения. Трекинговые параметры URL отбрасываются при сопоставлении. Группировка основана на адресах, совпадении текста и длинных заголовках за сутки. Смысловые переформулировки могут остаться отдельными событиями. Повтор после успешной записи доставки исключается; при аварии между приёмом сообщения Telegram и записью результата возможен повтор.

Календарь заполняется владельцем. Интерфейс бота русский. Оценка важности эвристическая. Видеосводка работает по текстовым правилам, а влияние на рынок и сравнение с прошлыми выступлениями требуют проверки человеком. Онлайн-приёмку токена, пользовательской сессии, модели и доступности выбранных каналов проводите на целевом компьютере.
